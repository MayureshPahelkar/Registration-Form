# Registration-Form
This project demonstrates the creation of a simple registration form using HTML, CSS, and PHP, designed to help beginners understand the fundamentals of web form handling and server-side validation. The form allows users to enter their name, email, and password through a clean and user-friendly interface styled with CSS.

When the user submits the form, the data is sent to the server using the POST method, where PHP processes the input. The program checks whether all required fields have been filled. If any field is left empty, the system displays a clear error message prompting the user to complete all fields. If all fields are correctly filled, the application displays a successful registration message along with the entered user details, which are shown inside a paragraph tag on the same page.

This project focuses on implementing basic server-side validation, handling user input securely, and dynamically displaying results without reloading or redirecting to another page. It is ideal for beginners who are learning how frontend and backend technologies work together and provides a strong foundation for more advanced features such as email validation, password encryption, and database integration.
